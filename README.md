# Red Campus

## Instalación y ejecución

### 1. Requisitos

Tener instalado:

- Node.js 18 o superior.

### 2. Instalar dependencias

Abrir una terminal dentro de la carpeta del proyecto y ejecutar:

```bash
npm install
```

### 3. Ejecutar la aplicación

```bash
npm run dev
```

### 4. Abrir en el navegador

Ingresar a la dirección que muestra la terminal, normalmente:

```text
http://localhost:5173
```

## Importante

No abrir el archivo `index.html` directamente. La aplicación debe ejecutarse con `npm run dev` para que cargue correctamente `data.json` si lo hace de esa manera impisble de abrir tenga en cuenta estas intruccion ante cualquier duda contactar a MiguelOni.
